# AI Disclaimer

## Use of AI tools

This project is developed with help from **[Claude Code](https://claude.com/claude-code)**, Anthropic's AI coding assistant. Claude Code has been used to:

- review the codebase and identify bugs and cleanup work (see [Todo.md](Todo.md))
- write project documentation, including [README.md](README.md) and this file
- assist with code changes

Commits that include AI-assisted work are marked with a `Co-Authored-By: Claude` trailer. All AI-generated output is reviewed by the maintainer, who remains responsible for the project's contents.

## Attribution

AI models are trained on large bodies of existing work and can reproduce ideas, structure or wording from it without saying where they came from. This project aims to credit outside sources as fully as possible, whether a contribution was written by a person or generated by AI.

Known sources and dependencies:

- **Qucs Technical Documentation**, §3.1.5 (Modified Nodal Analysis). The MNA formulation and the reference test circuit follow this text: <http://qucs.github.io/docs/technical/technical.pdf>
- **[nalgebra](https://nalgebra.org)**: linear algebra and LU solving
- **[assert_float_eq](https://crates.io/crates/assert_float_eq)**: floating-point test assertions

If you notice an uncredited source, please report it so it can be added.

## Requesting attribution

If you own or maintain a project, publication or other work and you believe this project uses it without credit, or credits it incorrectly or insufficiently, **please get in touch** by opening an issue on this repository or contacting the maintainer directly. Requests for clearer or more prominent attribution are welcome and will be taken seriously. Corrections will be made promptly, and where appropriate the material will be removed or reworked.
